# daily-tips

My daily-tips generated by LLM skill `/daily-tips`; it was originally in my
gists but wanted to share it to public for they are very good tips.

One non-obvious tip each for Rust, C++, and TypeScript. Every entry names the
minimum language or compiler version, cites a primary source, and closes with a
question it deliberately leaves unanswered.

F# has no row on purpose. It never gets a tip of its own, and appears only as
the control language in the functional-angle comparisons, where the question is
what a given shape costs in a language built for it.

`ledger.jsonl` is the machine-readable index: one JSON object per tip, with
`date`, `language`, `category`, `title`, `tags`, `sources`, and `related`.
